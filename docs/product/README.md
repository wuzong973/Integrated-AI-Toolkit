## 使用纪律

- 设计变更：先改 V2 文档的对应章节与「修订记录」，再动代码；
- 引用设计时用章节号（如「文档 6.2.6」），代码注释里也是同样写法；
- `.docx` 是导出物：改了 Markdown 就重新导出，不要直接编辑 `.docx`；
- 数据库选型已从 PostgreSQL 迁到 MySQL，见 `../architecture/DB-MIGRATION-POSTGRES-TO-MYSQL.md`。
