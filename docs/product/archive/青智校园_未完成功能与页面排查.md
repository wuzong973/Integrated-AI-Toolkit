| 未开工区域 | 缺口 | 任务编号 |
|---|---|---|
| **订单全链路** | `/orders/*` **7 个接口一个都没有**（状态机 / 担保支付 / 交付验收 / 退款仲裁） | M3-11~15 |

| **消息通知** | `/notifications` 缺 | M3-19 |

⚠️ **这些缺口的表现形式是"静默"的**，`tsc` / `eslint` / 单测都不会报错：

  并新增 `npm run audit:api` 防止再出现同类问题。
